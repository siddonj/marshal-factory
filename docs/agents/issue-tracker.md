# Issue tracker: Linear

Issues for this repo live in Linear, team key `RES` (issues are `RES-n`). Use the Linear MCP/CLI to create, read, comment on and label them. Do not use `gh issue`.

- The `factory` label hands an issue to the marshal-factory runner; `factory-failed` marks a failed run.
- The `Repository/{marshal-factory,evieai2}` label group says which repo an issue targets.
- GitHub (`siddonj/marshal-factory`) is for code and PRs only. Linear is the source of truth for work.
- Triage labels (see `triage-labels.md`) are Linear labels on the RES team; create any that are missing before applying.
